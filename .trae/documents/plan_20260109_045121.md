# 完成 Xianke 测试用例实现

## 1. 测试文件结构

* **文件路径**: `tests/vendors/vms/xianke/test_factory.py`

* **测试函数**: `test_frame_factory()`

* **测试框架**: 基于 Python 标准 `assert` 语句

## 2. 测试用例设计

根据 protocol.py 中的实际报文例子，为 `get_play_item` 和 `download_file` 方法编写测试用例：

### 2.1 测试方法

1. `get_play_item()` - 获取播放项
2. `download_file()` - 下载播放表

### 2.2 测试要点

* 验证帧对象转换为字节流后与实际报文例子完全匹配

* 验证帧对象的 `what` 属性是否正确

* 验证帧对象的 `data` 属性是否符合预期格式

## 3. 测试代码实现

```python
from highway_sdk.vendors.vms.xianke.factory import FrameFactory


def test_frame_factory():
    # 测试获取播放项 - 对应协议文档中的例子
    frame = FrameFactory.get_play_item()
    expected_hex = "02 32 34 30 30 EB 22 03"
    assert bytes(frame) == bytes.fromhex(expected_hex)
    assert frame.what.value == b"24"

    # 测试下载播放表 - 对应协议文档中的例子
    frame = FrameFactory.download_file(file_name="list\\000.xkl")
    expected_hex = "02 32 31 30 30 30 31 32 6C 69 73 74 5C 30 30 30 2E 78 6B 6C 30 30 30 30 3A 87 03"
    assert bytes(frame) == bytes.fromhex(expected_hex)
    assert frame.what.value == b"21"
    assert b"list\\000.xkl" in frame.data
```

## 4. 测试执行

测试用例编写完成后，可以通过以下命令执行测试：

```bash

```

* 验证帧对象的属性符合预期

* 确保帧对象可以成功转换为字节流
