# 设备Protocol支持Prometheus采集实现方案

## 实现概述

为设备通信协议添加Prometheus监控支持，实现对设备通信状态的实时监控和数据采集，设备ID自动生成，无需用户手动指定。

## 核心实现

### 1. 设备ID自动生成规则

| 协议类型 | 设备ID格式 | 示例 |
|---------|------------|------|
| TCP | tcp+ip+port | tcp192.168.1.100+8080 |
| UDP | udp+ip | udp192.168.1.100 |

### 2. 依赖添加

添加 `prometheus_client` 库作为依赖，用于实现Prometheus指标的定义和暴露。

### 3. 监控指标设计

实现以下核心监控指标：

| 指标名称 | 类型 | 描述 | 标签 |
|---------|------|------|------|
| device_connection_status | Gauge | 设备连接状态（0=断开, 1=连接） | device_id, host, port |
| device_reconnect_count | Counter | 设备重连次数 | device_id, host, port |
| device_request_total | Counter | 请求总数 | device_id, host, port, request_name, result |
| device_response_time_seconds | Histogram | 响应时间直方图 | device_id, host, port, request_name |
| device_bytes_sent_total | Counter | 发送字节数 | device_id, host, port |
| device_bytes_received_total | Counter | 接收字节数 | device_id, host, port |
| device_scheduled_jobs_total | Counter | 定时任务执行次数 | device_id, host, port, job_name |

### 4. 代码集成

#### 4.1 BaseConnector类
- 添加设备ID生成逻辑
- 在创建协议实例时传递设备ID

#### 4.2 TCPConnector类
- 实现TCP设备ID自动生成：`tcp+ip+port`

#### 4.3 UDPConnector类
- 实现UDP设备ID自动生成：`udp+ip`

#### 4.4 TCPClientProtocol类
- 接收设备ID参数
- 在 `connection_made` 方法中更新连接状态为1
- 在 `connection_lost` 方法中更新连接状态为0
- 在 `data_received` 方法中更新接收字节数
- 在 `send` 方法中更新发送字节数

#### 4.5 DriverTCPClientProtocol类
- 添加了 `_wrapped_scheduled_job` 方法，用于包装定时任务并添加监控
- 添加了 `add_interval_job_with_metrics` 方法，用于添加带监控的定时任务

#### 4.6 ReqRespTCPClientProtocol类
- 在 `request` 方法中添加了请求计数和响应时间监控
- 支持区分不同请求结果（success, timeout, error）

#### 4.7 AioTCPClient类
- 为异步TCP客户端也添加了完整的监控支持
- 包括连接状态、请求响应、数据传输等指标

### 5. Prometheus HTTP服务器

实现 `start_prometheus_server` 函数，用于启动异步HTTP服务器，默认监听8000端口。

### 6. 配置选项

添加配置选项，允许用户：
- 启用/禁用Prometheus监控
- 配置监控服务器端口
- 自定义监控指标前缀

## 使用方法

### 1. 启动监控服务

```python
from highway_sdk.core.protocols import start_prometheus_server

# 启动Prometheus服务器
start_prometheus_server(host='0.0.0.0', port=8000)
```

### 2. 访问监控指标

启动后，可以通过以下URL访问监控指标：
```
http://localhost:8000/metrics
```

### 3. 集成到现有代码

现有代码无需修改，设备ID会自动生成：

```python
# TCP连接
connector = TCPReconnectingConnector(
    host='192.168.1.100',
    port=8080,
    protocol_cls=ReqRespTCPClientProtocol
)

# UDP连接
udp_connector = UDPConnector(
    host='192.168.1.100',
    port=5000,
    protocol_cls=UDPProtocol
)
```

### 4. 带监控的定时任务

```python
# 使用带监控的定时任务添加方法
protocol.add_interval_job_with_metrics(
    func=my_job,
    seconds=30,
    job_name="temperature_check"
)
```

## 优势

1. **非侵入式设计**：对现有代码修改最小，易于集成
2. **设备ID自动生成**：无需用户手动指定，减少配置复杂度
3. **全面的监控覆盖**：涵盖连接、请求响应、数据传输、定时任务等方面
4. **异步支持**：完全兼容asyncio事件循环
5. **标准化**：使用Prometheus标准指标格式，易于集成到现有监控系统
6. **低开销**：指标更新操作开销极小，不会影响设备通信性能
7. **可扩展性**：设计的监控架构支持扩展更多指标
