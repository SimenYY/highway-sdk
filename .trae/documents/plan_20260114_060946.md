# 基于sans I/O设计模式的库优化方案

## 1. 问题分析

当前库与asyncio强绑定的核心问题：
- 协议实现直接继承自`asyncio.Protocol`
- 连接管理依赖asyncio特定API（如`asyncio.Lock`、`asyncio.sleep`）
- 事件处理与asyncio事件循环紧密耦合
- 异步客户端（如HTTP、MQTT）依赖asyncio特定实现
- 调度器使用`AsyncIOScheduler`

## 2. 优化目标

采用sans I/O设计模式，实现：
- 协议逻辑与I/O操作分离
- 事件循环框架的解耦
- 支持多种事件循环（asyncio、trio、curio等）
- 保持向后兼容性
- 提高代码可测试性和可维护性

## 3. 核心优化方案

### 3.1 协议层重构

**当前结构**：
```
asyncio.Protocol
    └── TCPClientProtocol
        └── DriverTCPClientProtocol
            └── 厂商特定协议（如VmsFenghaiProtocol）
```

**重构后结构**：
```
# 纯协议类（sans I/O）
BaseProtocol
    ├── BaseFrameProtocol
    │   └── VmsProtocol
    │       ├── FenghaiProtocol
    │       ├── NovaProtocol
    │       └── 其他厂商协议
    └── BaseStreamProtocol

# I/O适配器
BaseIOAdapter
    ├── AsyncioIOAdapter
    │   └── AsyncioTCPAdapter
    ├── TrioIOAdapter
    └── CurioIOAdapter
```

### 3.2 关键设计变更

#### 3.2.1 纯协议类设计

创建不依赖任何I/O的纯协议类：
- 处理帧解析和序列化
- 管理协议状态机
- 定义事件回调接口
- 操作字节缓冲区

**示例实现**：
```python
class BaseProtocol:
    def __init__(self):
        self._state = "idle"
        self._buffer = bytearray()
        self._callbacks = {}
    
    def feed_data(self, data: bytes) -> list[BaseTags]:
        """处理输入数据，返回解析后的消息"""
        pass
    
    def build_message(self, what: Any, **kwargs) -> bytes:
        """构建要发送的消息"""
        pass
    
    def on(self, event: str, callback: Callable):
        """注册事件回调"""
        self._callbacks[event] = callback
```

#### 3.2.2 I/O适配器设计

创建适配器类，负责：
- 处理实际I/O操作
- 连接管理
- 事件循环集成
- 将I/O事件转发给纯协议类

**示例实现**：
```python
class AsyncioTCPAdapter:
    def __init__(self, protocol: BaseProtocol, host: str, port: int):
        self._protocol = protocol
        self._host = host
        self._port = port
        self._transport = None
        self._loop = None
    
    async def connect(self):
        """建立连接"""
        self._loop = asyncio.get_running_loop()
        self._transport, _ = await self._loop.create_connection(
            lambda: self._create_protocol(),
            self._host,
            self._port
        )
    
    def _create_protocol(self):
        """创建asyncio.Protocol实例"""
        # 内部类，桥接asyncio.Protocol和纯协议类
        class _AsyncioProtocol(asyncio.Protocol):
            def connection_made(self, transport):
                self.transport = transport
            
            def data_received(self, data):
                messages = self.adapter._protocol.feed_data(data)
                for msg in messages:
                    if "message_parsed" in self.adapter._protocol._callbacks:
                        self.adapter._protocol._callbacks["message_parsed"](msg)
            
            def connection_lost(self, exc):
                pass
        
        proto = _AsyncioProtocol()
        proto.adapter = self
        return proto
```

### 3.3 具体优化组件

#### 3.3.1 核心协议模块

- 重构`TCPClientProtocol`和`DriverTCPClientProtocol`
- 提取纯协议逻辑到新的`BaseFrameProtocol`类
- 创建`AsyncioProtocolAdapter`桥接asyncio和纯协议

#### 3.3.2 连接器模块

- 重构`TCPReconnectingConnector`
- 使其支持不同的I/O适配器
- 使用依赖注入允许用户选择事件循环

#### 3.3.3 设备厂商协议

- 重构所有厂商特定协议（fenghai、nova、sansi、xianke等）
- 使其继承自纯协议类
- 移除直接asyncio依赖

#### 3.3.4 异步客户端

- 重构`SupaiotAPIClient`
- 允许用户提供自己的HTTP客户端实现
- 支持不同的异步HTTP客户端库

#### 3.3.5 调度器

- 抽象调度器接口
- 支持不同的调度器实现
- 移除直接`AsyncIOScheduler`依赖

#### 3.3.6 工具函数

- 重构`AppLock`类，支持不同的锁实现
- 重构装饰器，支持不同的同步机制

## 4. 向后兼容性

- 提供兼容层，允许现有代码继续工作
- 支持通过配置选择旧版asyncio实现或新版sans I/O实现
- 保持公共API不变，只修改内部实现

## 8. 示例使用方式

```python
# 旧版使用方式（保持兼容）
import asyncio
from highway_sdk.core.connectors import TCPReconnectingConnector
from highway_sdk.vendors.vms.fenghai.protocol import VmsFenghaiProtocol

async def main():
    connector = TCPReconnectingConnector(
        host="192.168.1.100",
        port=8888,
        protocol_cls=VmsFenghaiProtocol
    )
    await connector.create()
    # ...

# 新版使用方式（sans I/O）
from highway_sdk.core.protocols import FenghaiProtocol  # 纯协议类
from highway_sdk.core.io.adapters import AsyncioTCPAdapter  # asyncio适配器

async def main():
    # 创建纯协议实例
    protocol = FenghaiProtocol()
    protocol.on("message_parsed", lambda msg: print(f"收到消息: {msg}"))
    
    # 创建I/O适配器
    adapter = AsyncioTCPAdapter(
        protocol=protocol,
        host="192.168.1.100",
        port=8888
    )
    
    # 建立连接
    await adapter.connect()
    
    # 发送命令
    cmd = protocol.build_get_play_item_command()
    adapter.send(cmd)
    # ...
```

通过以上优化，库将实现I/O无关设计，提高事件循环框架替换的解耦性，同时保持良好的向后兼容性。
