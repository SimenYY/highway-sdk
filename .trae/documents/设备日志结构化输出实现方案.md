# 设备日志结构化输出实现方案

## 目标
将设备日志改为结构化输出，以便于集成到能够解析结构化日志的可视化平台中。

## 实现思路

### 1. 日志系统现状
- 使用 loguru 作为主要日志库，同时支持标准 logging 库
- 目前日志为文本格式，包含级别、时间、模块、函数、行号和消息
- 设备相关日志通过普通文本消息记录

### 2. 结构化日志设计

#### 2.1 核心修改点
- **文件**：`highway_sdk/core/log.py`
- **功能**：修改 LoguruConfig 类，添加 JSON 格式输出支持

#### 2.2 实现方案
1. **利用 loguru 内置 JSON 支持**：使用 loguru 的 `serialize=True` 参数实现 JSON 格式输出
2. **修改日志配置类**：在 LoguruConfig 类中添加 `serialize` 参数，与 loguru 库参数名保持一致
3. **支持配置切换**：允许通过配置选择文本格式或 JSON 格式输出
4. **向后兼容**：不修改现有代码的情况下，支持结构化日志输出

#### 2.3 JSON 格式特点
- 使用 loguru 内置的 JSON 序列化功能
- 包含所有原始日志字段（级别、时间、模块、函数、行号、消息等）
- 自动处理额外字段和上下文信息
- 符合常见日志可视化平台的要求

### 3. 代码实现

#### 3.1 修改日志配置类
```python
class LoguruConfig:
    """配置loguru

    注释：
        1. 能够添加拦截原生的logger
        2. 能够配置console和file两种常用输出
        3. 支持JSON格式输出
    """

    def __init__(
        self,
        name: str,
        level: str = "DEBUG",
        serialize: bool = False  # 与loguru一致的参数名
    ):
        loguru.logger.remove()

        self.name = name
        self.level = level
        self.serialize = serialize

    def set_console(self) -> None:
        """配置控制台输出，支持JSON格式
        
        Args:
            format: 日志格式，默认为None使用默认格式
        """
        loguru.logger.add(
            sys.stdout, 
            level=self.level,
            serialize=self.serialize  # 使用与loguru一致的参数名
        )

    def set_file(
        self,
        log_dir: Path | str = "logs",
        *,
        rotation: str = "00:00",
        retention: str = "3 days",
        compression: str = "zip",
        enqueue: bool = True,
    ):
        """配置文件输出，支持JSON格式
        
        Args:
            log_dir: 日志目录
            rotation: 日志文件轮转规则
            retention: 日志保留时间
            compression: 日志压缩格式
            enqueue: 是否使用异步写入
        """
        log_dir = Path(log_dir)
        log_dir.mkdir(parents=True, exist_ok=True)
        log_file = log_dir / self.name / (f"{self.name}" + "_{time:YYYY-MM-DD}.log")
        loguru.logger.add(
            str(log_file),
            level=self.level,
            rotation=rotation,
            retention=retention,
            compression=compression,
            enqueue=enqueue,
            serialize=self.serialize  # 使用与loguru一致的参数名
        )
```

#### 3.2 使用示例
```python
# 配置 JSON 格式日志
log_config = LoguruConfig(name="my_app", level="INFO", serialize=True)
log_config.set_console()
log_config.set_file()

# 获取logger
logger = logging.getLogger(__name__)

# 记录设备日志（现有代码无需修改，自动转为 JSON 格式）
logger.info(f"设备 {device_id} 连接成功")
logger.error(f"设备 {device_id} 通信失败: {error}")
```
