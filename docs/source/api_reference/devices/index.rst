设备类型概述
------------

Highway SDK支持多种设备类型，每种设备类型都有对应的API和实现。

CMS (可变信息标志)
-------------------

CMS设备用于在高速公路上显示可变信息，如路况、天气、事故信息等。

请参考 `cms <cms>`_ 模块的API文档。

VD (车检器)
------------

VD设备用于检测车辆流量、速度、占有率等信息。

请参考 `vd <vd>`_ 模块的API文档。

扩展新设备类型
---------------

要扩展新的设备类型，需要：

1. 在 `highway_sdk/vendors/` 目录下创建新的设备类型目录
2. 实现设备类型的基础类和工具
3. 为每个厂商实现创建对应的目录和文件
4. 在 `highway_sdk/vendors/__init__.py` 中导出新的设备类型
5. 更新文档，添加新设备类型的API参考
