厂商实现概述
------------

厂商实现是针对特定厂商设备的协议实现，Highway SDK采用模块化设计，便于扩展新的厂商支持。

**每个厂商实现包含以下文件**：

- `spec.py` - 协议规范，定义指令码（What 枚举）、帧结构、CRC 计算、转义规则
- `codec.py` - 编解码器，继承 `BaseCodec`，使用 `@BaseCodec.register(What.XXX)` 注册解码器
- `device.py` - 设备客户端，继承 `BaseDevice[VendorCodec]`，实现数据采集与控制 API

扩展新厂商实现
----------------

要扩展新的厂商实现，需要：

1. 根据设备类型，在对应的设备类型目录下创建厂商目录
2. 实现上述三个核心文件
3. 在厂商 ``__init__.py`` 中导出 ``metadata``（``VendorMetadata`` 实例），SDK 会在 ``vendors/__init__.py`` 自动注册
4. 编写测试用例（参考 ``tests/vendors/cms/``）
5. 更新文档

厂商实现测试
--------------

每个厂商实现都应该有对应的测试用例，确保实现的正确性和稳定性。

**测试内容**：

- 协议帧序列化与解析测试
- 编解码器单元测试
- 设备接口编排测试（使用 FakeTransport）
- 真实报文测试（基于实际设备通信日志或协议标准报文）

厂商实现版本管理
------------------

厂商实现支持版本管理，可以为同一厂商的不同协议版本提供不同的实现。

**版本管理方式**：

- 在厂商 ``metadata.version`` 字段标注协议版本
- 不同版本的实现以独立目录或类名后缀区分
