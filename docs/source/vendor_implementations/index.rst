厂商实现概述
------------

厂商实现是针对特定厂商设备的协议实现，Highway SDK采用模块化设计，便于扩展新的厂商支持。

**每个厂商实现包含以下文件**：

- **factory.py** - 帧工厂，用于创建设备通信的请求帧
- **parser.py** - 解析器，用于解析设备返回的数据
- **protocol.py** - 协议实现，用于处理设备通信
- **spec.py** - 协议规范，定义指令码、帧结构等
- **media.py** - 媒体管理，用于处理设备的媒体文件

扩展新厂商实现
----------------

要扩展新的厂商实现，需要：

1. 根据设备类型，在对应的设备类型目录下创建厂商目录
2. 实现上述五个核心文件
3. 确保与现有API保持一致
4. 编写测试用例
5. 更新文档

厂商实现测试
--------------

每个厂商实现都应该有对应的测试用例，确保实现的正确性和稳定性。

**测试内容**：

- 协议通信测试
- 帧工厂测试
- 解析器测试
- 媒体管理测试
- 异常处理测试

厂商实现版本管理
------------------

厂商实现支持版本管理，可以为同一厂商的不同协议版本提供不同的实现。

**版本管理方式**：

- 在厂商目录下创建版本子目录，如 `v1_0_0`、`v2_0_0` 等
- 为每个版本实现对应的协议、帧工厂和解析器
- 提供版本选择机制，允许用户选择使用哪个版本的实现
