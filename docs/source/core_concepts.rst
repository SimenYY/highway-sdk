核心概念
==========

Highway SDK 引入了一些核心概念，理解这些概念将有助于您更好地使用和扩展 SDK。

协议 (Protocol)
---------------

**定义**：协议是设备通信的规则和格式的抽象，定义了设备如何发送和接收数据。

**类型**：
- **DriverTCPClientProtocol** - 基本的TCP客户端协议，用于处理设备通信
- **MonitoredDriverTCPClientProtocol** - 带监控功能的TCP客户端协议
- **ReqRespTCPClientProtocol** - 请求响应模式的TCP客户端协议
- **MonitoredReqRespTCPClientProtocol** - 带监控功能的请求响应模式TCP客户端协议

**作用**：
- 处理设备连接的建立、维护和关闭
- 处理设备数据的发送和接收
- 解析设备返回的数据
- 触发相应的回调函数处理设备事件

连接器 (Connector)
-------------------

**定义**：连接器负责管理设备连接的生命周期，包括连接的建立、重连和关闭。

**类型**：
- **TCPReconnectingConnector** - TCP重连连接器，支持自动重连
- **UDPConnector** - UDP连接器

**作用**：
- 管理设备连接的建立和关闭
- 处理连接失败的情况，实现自动重连
- 提供设备连接状态的监控
- 简化设备连接的使用方式

设备ID (Device ID)
-------------------

**定义**：设备ID是设备的唯一标识符，用于区分不同的设备。

**生成规则**：
- 对于TCP连接，设备ID格式为：`tcp+host+port`
- 对于UDP连接，设备ID格式为：`udp+host`

**作用**：
- 用于设备状态的监控和统计
- 用于设备管理和识别
- 用于日志记录和调试

日志配置 (Log Config)
----------------------

**定义**：日志配置用于配置SDK的日志输出格式、级别和位置。

**核心类**：
- **LoguruConfig** - 日志配置类，用于配置日志输出

**作用**：
- 配置日志输出格式（文本或JSON）
- 配置日志输出位置（控制台或文件）
- 配置日志级别（DEBUG, INFO, WARNING, ERROR, CRITICAL）
- 拦截和处理第三方库的日志

监控 (Metrics)
---------------

**定义**：监控功能用于收集设备的连接状态和性能指标。

**核心组件**：
- **MetricsMixin** - 监控混入类，用于为协议类添加监控功能
- **start_prometheus_server** - 启动Prometheus监控服务器

**作用**：
- 收集设备的连接状态
- 收集设备通信的性能指标
- 提供Prometheus兼容的监控端点
- 支持监控数据的可视化

帧工厂 (Frame Factory)
----------------------

**定义**：帧工厂用于创建设备通信的请求帧。

**作用**：
- 根据设备协议规范创建请求帧
- 封装请求帧的创建逻辑
- 提供一致的API接口，简化请求帧的创建

解析器 (Parser)
---------------

**定义**：解析器用于解析设备返回的数据，将原始数据转换为结构化的标签。

**作用**：
- 解析设备返回的原始数据
- 将原始数据转换为结构化的标签对象
- 处理数据解析错误
- 提供一致的数据解析接口

标签 (Tags)
-----------

**定义**：标签是设备数据的结构化表示，包含设备的状态和信息。

**作用**：
- 统一设备数据的表示方式
- 提供易于访问和使用的数据结构
- 支持数据的序列化和反序列化
- 便于数据的处理和分析

厂商实现 (Vendor Implementation)
--------------------------------

**定义**：厂商实现是针对特定厂商设备的协议实现。

**结构**：
- **factory.py** - 帧工厂实现
- **parser.py** - 解析器实现
- **protocol.py** - 协议实现
- **spec.py** - 协议规范定义
- **media.py** - 媒体管理实现

**作用**：
- 实现特定厂商设备的通信协议
- 提供厂商特定的功能和API
- 封装厂商协议的细节，提供统一的接口

平台集成 (Platform Integration)
--------------------------------

**定义**：平台集成用于将SDK与外部平台集成，实现设备数据的上传和管理。

**作用**：
- 将设备数据上传到外部平台
- 接收外部平台的命令和配置
- 实现设备的远程管理和监控
- 支持多种平台的集成

消息 Broker (Message Broker)
------------------------------

**定义**：消息Broker用于实现设备数据的发布和订阅。

**类型**：
- **MQTTBroker** - MQTT消息Broker
- **KafkaBroker** - Kafka消息Broker
- **RedisBroker** - Redis消息Broker

**作用**：
- 实现设备数据的发布和订阅
- 支持设备之间的消息传递
- 实现设备数据的广播和分发
- 支持多种消息协议
