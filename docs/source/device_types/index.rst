设备类型
==========

Highway SDK支持多种设备类型，每种设备类型都有对应的API和实现。

.. toctree::
   :maxdepth: 2
   :caption: 设备类型

   cms
   vd

设备类型概述
------------

设备类型是设备的分类，每种设备类型都有其特定的功能和通信协议。

设备类型管理
------------

Highway SDK使用模块化设计来管理不同的设备类型，每种设备类型都有自己的目录结构和实现。

设备类型扩展
------------

要扩展新的设备类型，需要：

1. 在 `highway_sdk/vendors/` 目录下创建新的设备类型目录
2. 实现设备类型的基础类和工具
3. 为每个厂商实现创建对应的目录和文件
4. 更新文档，添加新设备类型的说明

设备类型列表
------------

CMS (可变信息标志)
^^^^^^^^^^^^^^^^^^

CMS设备用于在高速公路上显示可变信息，如路况、天气、事故信息等。

请参考 `cms <cms>`_ 文档。

VD (车检器)
^^^^^^^^^^^^

VD设备用于检测车辆流量、速度、占有率等信息。

请参考 `vd <vd>`_ 文档。
